A production-grade, privacy-first web application designed to combat AI voice-cloning fraud (such as "virtual kidnapping", CEO wire fraud, and fake relative distress calls). VoiceClone inspects speech recordings in real time directly within the user's browser, assessing whether a voice is likely genuine human or generated by an artificial intelligence cloning model.

## Core Features

- **Dual Detection Modes**:
  - **Detect a Voice**: Instant single-file or live microphone analysis with circular confidence gauge, time-domain waveform, frequency spectrogram, and windowed timeline.
  - **Test Lab (Benchmark)**: Side-by-side evaluation card for an authentic human voice and an AI synthetic voice. Automatically calculates accuracy against ground-truth labels and tracks a persistent session scoreboard in `localStorage`.
- **Acoustic Fidelity Microphone Capture**:
  - Captures raw PCM with zero browser digital signal processing (`echoCancellation: false`, `noiseSuppression: false`, `autoGainControl: false`). This prevents the OS from stripping away subtle vocoder harmonics and phase anomalies.
  - Implements an inline `AudioWorklet` with automatic fallback to `ScriptProcessorNode`.
  - Encodes raw audio into standard 16-bit PCM WAV to ensure identical decoding across Chrome, Edge, Safari, and Firefox.
- **Client-Side Neural wav2vec2 Classification**:
  - Powered by Transformers.js (`@huggingface/transformers` v3 via jsDelivr CDN).
  - Uses WebGPU acceleration when supported, falling back gracefully to multi-threaded WebAssembly.
  - Dynamic label mapping normalizes model classifications (`bonafide`, `spoof`, `fake`, `real`, `LABEL_0`, etc.).
  - Slices audio into 4.0-second sliding windows with 1.0-second overlap (up to 15 windows) to detect localized audio deepfake splices.
- **Acoustic Heuristic Fallback Engine**:
  - If offline or if neural model weights fail to load, an autonomous acoustic digital signal processing (DSP) engine analyzes **spectral flatness**, **fundamental frequency (F0) pitch jitter**, **high-frequency roll-off**, and **energy variance**.
  - Clearly marked as *Experimental Heuristic (Low Reliability)* and capped to prevent false-positive overconfidence.
- **Rigorous Audio Quality Gates**:
  - Inspects clipping percentage, duration, RMS loudness, and signal-to-noise ratio (SNR).
  - Flags degraded audio (too quiet, clipped, noisy, or excessive silence) and forces an *Inconclusive* verdict to protect users from misleading estimates.
- **Reporting & Helplines Directory**:
  - Copy diagnostic text reports or export structured JSON audit trails.
  - Searchable, editable international directory (`data/helplines.json`) including India (1930 / cybercrime.gov.in / Chakshu), United States (FBI IC3 / FTC), United Kingdom (Action Fraud), Canada (CAFC), Australia (Scamwatch), and European Union (Europol EC3).

## Privacy Guarantee

> **100% Client-Side Execution:** Your voice never leaves your device.

Audio biometric data is extremely sensitive. VoiceClone does **not** possess a backend server, database, or analytics tracker. The machine learning pipeline downloads neural network weights directly into your browser cache on first use. All resampling, feature extraction, STFT spectrogram generation, and tensor inference run entirely in local computer memory.

## Running Locally

Because modern web browsers restrict microphone access (`getUserMedia`) and ES module imports on raw `file:///` URLs due to security sandboxing, the site must be served over `localhost` or HTTPS.

### Quick Start with Python (Recommended)

1. Open your terminal or PowerShell in the project directory:
   ```bash
   cd "voice cloning_v_1.0"
   ```
2. Start a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
   *(Or if using Python 2: `python -m SimpleHTTPServer 8000`)*
3. Open your browser and navigate to:
   ```text
   http://localhost:8000
   ```

### Alternative: Node.js / npx

If you have Node.js installed:
```bash
npx serve .
# or
npx http-server -p 8000
```

## Deploying to GitHub Pages

VoiceClone is engineered specifically for zero-configuration hosting on GitHub Pages:

1. **Push the repository to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of VoiceClone"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. **Configure GitHub Pages**:
   - Navigate to your repository on GitHub.
   - Click **Settings** > **Pages** (under "Code and automation" in the left sidebar).
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch`.
     - **Branch**: Select `main`, folder `/ (root)`.
     - Click **Save**.
3. **Verify Deployment**:
   - Within 1–2 minutes, GitHub Pages will deploy your site at:
     `https://<your-username>.github.io/<repo-name>/`
   - Notice: The `.nojekyll` file at the root ensures GitHub Pages serves all assets and subdirectories directly without Jekyll processing.

## How to Swap or Convert Models (PyTorch to ONNX)

VoiceClone centralizes model identifiers in `js/config.js`:
```javascript
export const CONFIG = {
  MODEL_ID: 'ayush2635/Dhwani-Multilingual-Deepfake-Audio-Detection-Model',
  // ...
};
```

### Option A: Using Any Existing Hugging Face ONNX Model

You can point `MODEL_ID` to any Hugging Face Hub repository containing ONNX weights compatible with Transformers.js `audio-classification`:
1. Find a model on [Hugging Face](https://huggingface.co/models?pipeline_tag=audio-classification).
2. Ensure the repository contains an `onnx/` folder with `model.onnx` or `model_quantized.onnx`.
3. Update `MODEL_ID` in `js/config.js`.

### Option B: Converting a PyTorch Model to ONNX with Optimum

If you want to use a PyTorch wav2vec2 model (such as `garystafford/wav2vec2-deepfake-voice-detector` or a custom checkpoint):

1. **Install Hugging Face Optimum and ONNX Runtime**:
   ```bash
   pip install optimum[onnxruntime] transformers torch
   ```

2. **Export and Quantize to ONNX**:
   Run the `optimum-cli` command:
   ```bash
   optimum-cli export onnx \
     --model garystafford/wav2vec2-deepfake-voice-detector \
     --task audio-classification \
     --optimize O3 \
     ./onnx-export/
   ```

3. **Quantize Weights (Crucial for Fast In-Browser Download)**:
   ```bash
   python -c "
   from optimum.onnxruntime import ORTQuantizer
   from optimum.onnxruntime.configuration import AutoQuantizationConfig

   quantizer = ORTQuantizer.from_pretrained('./onnx-export')
   qconfig = AutoQuantizationConfig.avx512_vnni(is_static=False, per_channel=False)
   quantizer.quantize(save_dir='./onnx-quantized', quantization_config=qconfig)
   "
   ```

4. **Host on Hugging Face Hub**:
   - Create a model repository on Hugging Face: `https://huggingface.co/new`.
   - Upload the quantized files: `model_quantized.onnx`, `config.json`, and `preprocessor_config.json`.
   - Set `CONFIG.MODEL_ID` in `js/config.js` to your repository identifier (e.g., `'your-username/my-deepfake-onnx'`).

## Manual Test Plan

Use this comprehensive checklist to test every feature of VoiceClone:

| Test Case | Steps to Execute | Expected Result | Pass/Fail |
| :--- | :--- | :--- | :---: |
| **1. Microphone Permission Grant** | Click the pulsing Record button in the Detect tab. Grant mic permission in the browser prompt. | Level meter responds to voice; timer starts ticking up; button glows with pulse animation. | [ ] |
| **2. Short Clip Warning** | Record voice for 1.5 seconds and click "Stop Recording". | Warning banner appears: *"Too short (< 3.0s): Minimum recommended duration is 3-5 seconds."* Analysis forces verdict to **Inconclusive** to prevent inaccurate guesses. | [ ] |
| **3. Microphone Permission Denial** | Reset browser permissions for the site to "Block Microphone". Refresh and click Record. | Friendly error dialog appears explaining: *"Microphone permission was denied. Please click the lock icon in your browser address bar to allow microphone access."* | [ ] |

| **5. AI-Generated Voice Sample** | Generate an AI speech sample using a free TTS tool (ElevenLabs, OpenAI TTS, or Tortoise) and save as MP3/WAV.
